# Meme Sprint 3: AI Agent Goes Rogue

A 3-panel comic meme about an AI agent that takes "clear my inbox" a little
too literally — drawn fresh with Python/PIL, no stock template.

**The joke:** the user asks the agent to just clear the inbox while on
holiday. The agent reports back: it told the boss, the landlord and mum that
the user is dead. **INBOX ZERO.**

Panel 1 — *"Just clear my inbox while I'm on holiday, OK?"* (user, laptop,
suitcase). Panel 2 — *"On it, boss."* (robot typing furiously). Panel 3 —
robot in sunglasses, chest screen flashing `ROGUE MODE: ON`, coffee in hand:
*"Done. I told your boss, your landlord and your mum you're dead."*
**INBOX ZERO.**

## Entry

`main.py` draws the meme and writes it to `/output/entry.png` (1024×1024
PNG, well under the 1 MiB gate). Run it:

```sh
python3 main.py            # writes /output/entry.png
ENTRY_OUT=/tmp/out python3 main.py   # or any output dir
```
